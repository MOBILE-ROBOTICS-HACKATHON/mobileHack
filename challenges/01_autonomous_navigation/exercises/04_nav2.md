## Questions / experiments
1. In rviz toggle: Global Costmap, Local Costmap, Global Plan, Local Plan, Particle Cloud. Explain each one.
2. Put a new obstacle in Gazebo (Insert > box) on the path. Does it replan? Which layer sees it?
3. Cancel a goal mid-way from Python (`nav.cancelTask()`); add a timeout.
4. Find the params file: `/opt/ros/humble/share/turtlebot3_navigation2/param/waffle.yaml`. Copy it to `experiments/`, change `max_vel_x`, `inflation_radius`, `robot_radius`, controller plugin (try MPPI: `nav2_mppi_controller::MPPIController`), and compare behaviour (time-to-goal, near-collisions).
5. Run with `ros2 bag record -a`, replay, and inspect `/plan` and `/local_costmap/costmap`.

## Typical failure modes (learn to recognise)
| Symptom | Cause |
|---|---|
| "Robot won't move, goal rejected" | no `map→odom` TF → not localized yet; set initial pose |
| Robot oscillates / spins | controller too aggressive or wrong footprint; lower vel/accel |
| Path through obstacles | costmap not receiving scan (QoS/frame/topic remap) |
| "Failed to make progress" recovery loops | inflation too large for a narrow passage |
| Everything jerky in sim | `use_sim_time` mismatch between nodes |
